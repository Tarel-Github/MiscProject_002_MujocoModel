# 다음 단계

Phase 1–5는 구현·검증되었습니다. 남은 작업과 개선 후보입니다.

## 검증
- Windows 11 실기 GUI 검증 (OpenGL compatibility 프로파일, 고해상도 DPI, 파일 대화상자 경로).

## 품질 (Phase 6)
- 대형 메시 모델의 비동기 컴파일과 진행 표시.
- 크기 조절 기즈모, 메시 데이터 자체의 변환(굽기) 도구.
- `<include>` 구조를 유지한 채 저장 (현재는 인라인화).
- 경고 패널(컴파일 경고, 불안정 이력) 강화.

## 표정
- Blender GLB의 추가 제어 본(입꼬리, 눈썹 등)을 표정 파라미터에 매핑하는 UI.
- 표정 시간 트랙 편집 UI(현재 API·project.json에서 지원), 녹화/재생.
- 재질·텍스처(glTF baseColor) 가져오기.

## 물리
- 균형/보행 제어기 예제, 근육(`<muscle>`)·tendon 기반 손가락 구동 옵션.
- 피부 접촉 센서의 공간 분해능 향상(분절당 다중 touch site), 통각 등 확장 감각 채널(`SensorBus.register`).
