# 해부학 부품 모델

`src/mjstudio/library/anatomy.py`의 생성기는 에디터의 범용 연산(`core/ops.py`)만 사용합니다(에디터에 하드코딩된 인간형 로직 없음).
좌표계는 MuJoCo 인간형 관례: **x 전방, y 왼쪽, z 위**. 왼쪽 부품을 정의하고 오른쪽은 거울상입니다
(위치 y→−y, 경첩축은 축벡터 규칙 `a' = (−aₓ, a_y, −a_z)`) — 같은 양의 각도가 양쪽에서 같은 해부학적 동작을 의미합니다.
치수는 성인(약 1.75 m) 평균 근사값이며 `scale`로 조절합니다. 가동 범위는 일반적인 능동 가동 범위(ROM) 근사입니다.

## 손 (`build_hand`, 22 관절)

손바닥 프레임(왼손, 해부학적 자세): 원점 = 손목 관절 중심, 손가락 = −z, 손바닥 = +x, 엄지(요측) = +y.
굽힘 축 −y → **양의 각도 = 굴곡**.

| 손가락 | 관절 | 자유도 | 범위(°) |
|---|---|---|---|
| 검지·중지·약지·소지 | MCP (`*_mcp_flex`, `*_mcp_abd`) | 굽힘 + 벌림/모음 | 굽힘 −20…90, 벌림 −15…20(중지 ±15, 소지 −15…25) |
| | PIP (`*_pip`) | 굽힘 | −5…105 |
| | DIP (`*_dip`) | 굽힘 | −5…85 |
| 엄지 | CMC (`thumb_cmc_rot`, `thumb_cmc_abd`) | 회전(굴곡/대립 방향 쓸기) + 손바닥 쪽 벌림 | −20…50, −10…55 |
| | MCP (`thumb_mcp`) | 굽힘 | −10…55 |
| | IP (`thumb_ip`) | 굽힘 | −15…80 |
| 손목(선택) | `wrist_flex`, `wrist_dev` | 굴곡/신전, 요측/척측 편위 | −70…80, −30…20 |

- 지골 길이: Alexander & Viktor (2010), Buryanov & Kotiuk (2010)의 성인 평균에 근거한 근사값 (예: 중지 45/27/20 mm).
- 각 지골(근위·중위·원위)과 손바닥에 별도 접촉 영역(site + `touch` 센서), 모든 관절에 `jointpos` 센서와 position 액추에이터.
- 손 내부 자기충돌은 비트마스크로 끔(`contype=2, conaffinity=1`): 손가락끼리는 충돌하지 않고 바닥·물체와는 충돌.

**해부학과 다른 점**: 엄지 CMC(안장관절)의 두 축은 실제로는 직교하지 않고 한 점에서 만나지 않으며 동반 축회전(conjunct rotation)을 만듭니다.
모델은 한 점의 직교 경첩 2개로 근사합니다. 중수골(검지~소지)은 손바닥 강체에 포함되며 CMC 4/5의 미세 운동(손바닥 오목)은 생략했습니다.

## 발 (`build_foot`)

프레임: 원점 = 거퇴관절(발목) 중심, 바닥 z = −0.075, x 전방.

| 분절 (body) | 관절 | 양의 방향 | 범위(°) | 비고 |
|---|---|---|---|---|
| 1 발목 연결부 `talus` | 거퇴관절 `ankle_flex` | 배측굴곡 | −50…25 | 축: 약 8° 하외측 경사, 약 8° 후외측 (Inman) |
| 2 후족부 `hindfoot` | 거골하관절 `subtalar` | 내번 | −10…25 | 축: 수평면 대비 42° 상승, 장축 대비 23° 내측 (Inman/Manter 평균) — "좌우 기울임" |
| 3 중족부 `midfoot` | 횡족근(쇼파르) `midtarsal` | 배측굴곡 | −8…8 | 강성 800 N·m/rad (체중 하 약 2° 변형) |
| 4 전족부 `forefoot` | 족근중족(리스프랑) `tmt` | 배측굴곡 | −5…5 | 강성 800 N·m/rad |
| 5 발가락 `toes` | 중족지 `mtp` | 배측굴곡 | −35…70 | 사선 중족골 굴곡선(1번이 전내측, 5번이 후외측, 장축과 약 58°) |

- 충돌·접촉 영역 분리: 뒤꿈치 `heel`(캡슐), 중족 외측 `midfoot_lateral`, 전족부 볼 `ball`(중족골두를 잇는 사선 캡슐), 발가락 `toes_pad`;
  touch 센서 `heel_zone`, `forefoot_zone`, `toes_zone`.
- **발등(dorsum)은 분절이 아니라** 중족부·전족부 geom(`midfoot_dorsum`, `forefoot_dorsum`)의 윗면 영역입니다.
- `toes="detailed"`: 엄지발가락(MTP+IP), 2~5지(MTP+PIP+DIP) 개별 관절 (선택 확장).

**해부학과 다른 점**: 거퇴·거골하 축은 개인차가 큰데 평균 방향 하나로 고정. 쇼파르(종축/사축 2축)와 리스프랑 관절을 각각 강성 있는
시상면 경첩 1개로 축약. `toes="single"`에서는 5개 MTP를 사선 굴곡선 위 경첩 하나로 합침. 족저근막 윈드라스 기전은 강성으로만 근사.

**검증** (`tests/test_anatomy.py`, 40 kg 하중 수직 활주 다리 리그):
- 발목만 움직일 수 있는가 → 발목 각만 바꾸면 원위 분절은 강체로 함께 회전, 정강이 불변
- 평발 서기 → 뒤꿈치 touch > 20 N, 전족부+발가락 touch > 20 N
- 발목 −30° 저측굴곡 + MTP 30° → **뒤꿈치 touch = 0, 전족부+발가락 > 100 N**, 몸 3 cm 이상 상승, MTP > 15°
- 공중에서 MTP 목표 40°/−20° 추종 (±3°)

## 머리·눈·턱 (`build_head`)

프레임: 머리 중심, x 전방.

| 관절 | 양의 방향 | 범위(°) | 비고 |
|---|---|---|---|
| `eye_<side>_yaw` | 왼쪽 보기 | −45…45 | 안구 반경 12 mm, 동공간 거리 63 mm |
| `eye_<side>_pitch` | 위 보기 | −45…30 | 하방(내림) 범위가 상방보다 큼 |
| `jaw_open` | 벌림 | 0…30 | 측두하악관절(TMJ) 회전 성분 |
| `jaw_protrude` (선택) | 전방 활주 | 0…10 mm | TMJ 병진 성분 |
| `neck_pitch/yaw/roll` | | −40…50 / ±70 / ±35 | 단일 점 3축 근사 |

- 시선 방향 읽기: 동공 앞 site의 x축을 `framexaxis` 센서(`gaze_dir_left/right`)로, 각도는 `jointpos` 센서로 제공.
- 양안 독립 제어(관절별 액추에이터)와 연동 제어(프로젝트의 관절 그룹 `gaze_yaw`, `gaze_pitch`)를 모두 지원.
  물리적으로 묶지 않으므로 독립 제어가 막히지 않습니다. 눈 회전은 표정 시스템과 별개의 관절 제어입니다.
- 턱은 머리에서 분리된 body로 경첩 연결, 관절 위치·축은 일반 속성 편집/기즈모로 수정 가능, 외부 메시 부착은 Phase 3에서 지원 예정.

**해부학과 다른 점**: 실제 안구 회전은 6개 외안근에 의한 3자유도(비틀림 포함, Listing 법칙)인데 수평/수직 2자유도로 단순화.
턱은 회전 후 전방 활주가 결합된 운동인데 독립 관절 2개로 근사. 목은 7개 경추를 단일 점 3축으로 근사.
